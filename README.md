# 🐧 Penguin Name Challenge

A fun interactive penguin quiz where you identify different penguin species from pictures!

## 🎮 Features

- 🐧 Penguin identification quiz
- 🟢 Easy level
- 🟡 Medium level
- 🔴 Hard level
- 🟣 Impossible level
- 🔥 Streak system
- ⭐ Score system
- 💡 Hint system
- 🏆 Achievements
- 📖 Penguin Encyclopedia
- 🔗 Wikipedia links for more information
- 💾 Saves your best score and completed levels
- 📱 Mobile-friendly design
- 🎞️ Slide-based page navigation

## 📚 Penguin Encyclopedia

The website includes information about different penguin species, including:

- Emperor Penguin
- King Penguin
- African Penguin
- Little Penguin
- Gentoo Penguin
- Chinstrap Penguin
- Adélie Penguin
- Macaroni Penguin
- Rockhopper Penguin
- Yellow-eyed Penguin

You can tap a penguin in the encyclopedia to open its Wikipedia article.

## 🌐 Images

Penguin images are loaded using the Wikipedia API, so the website can automatically get current thumbnail images for the penguin species.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Wikipedia API
- Local Storage

## 🚀 How to Use

1. Open the website.
2. Press **Play**.
3. Choose a difficulty.
4. Look at the penguin.
5. Type its name.
6. Submit your answer.
7. Try to build the biggest streak!
